# Customer Shopping Behavior Analysis

## Project Overview
This project analyzes customer shopping behavior to understand purchasing patterns, sales performance, customer preferences, and subscription trends.

## Tools & Technologies
- Python (Pandas, Matplotlib)
- SQL (PostgreSQL)
- Power BI
- Excel

## Project Files
- `Customer_behavior.ipynb` – Data cleaning and exploratory data analysis.
- `Sql_Queries.sql` – SQL queries for business analysis.
- `Customer_behavior_Dashboard.pbix` – Interactive Power BI dashboard.
- `customer_shopping_behavior.csv` – Dataset used for analysis.
- `customer_shopping_behavior.xls` – Excel version of the dataset.

## Key Analysis
- Revenue by product category
- Customer purchasing patterns
- Sales by age group
- Gender-based shopping trends
- Subscription status analysis
- Payment method preferences
- Customer reviews and ratings

## Project Objective
To turn raw customer shopping data into meaningful business insights that can support better business decisions.
